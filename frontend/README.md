# NextGen AutoWorkshop Web

Interfaz local de recepción para un único taller.

```powershell
npm install
npm run dev
```

Abre `http://localhost:5173`. En **Configuración** ingresa los IDs creados al ejecutar `/v1/setup/bootstrap`. El token local por defecto es `local-development-token`.

La API debe estar ejecutándose en `http://localhost:3000`.
